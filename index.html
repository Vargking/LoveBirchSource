关于版本、安装，以及一点小提示。

正常版与 NoJRE 版有什么区别？

JRE 是运行应用所需的 Java 环境。正常版自带这个环境；NoJRE 版不带，需要你自行准备 64 位 Java 21+。应用功能相同。如果你不知道 JRE 是什么，就下载正常版。

Android 与 Android TV 可以一起安装吗？

可以。手机版包名为 cn.vargking.lovebirch，TV 版为 cn.vargking.lovebirch.tv，更新清单也相互独立。TV 版面向遥控器使用，不包含视频下载器和本地播放功能。

TV 播放器怎样使用遥控器？

预览画面按确认进入全屏；全屏画面按确认暂停或继续。画面或进度条获得焦点时，左右方向键快退 / 快进 10 秒；上下键移动到控制栏，还可操作倍速、设置与选集换源。返回键退出全屏。

如何升级？我的记录会丢失吗？

使用相同版本类型的新安装包覆盖升级，通常无需卸载。Windows 客户端下载并校验更新后会启动 Setup，Android 则交由系统安装界面确认。请勿主动删除应用数据；重要记录建议提前备份。

应用是否内置影视内容？

LoveBirch 是播放与数据源管理客户端，不提供或托管影视内容。内容能否访问取决于你配置的数据源、网络与服务方。请仅使用可信数据源，并遵守相关法律及内容授权。
